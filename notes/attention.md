# 注意力机制

# 文章内容摘记

从直观上讲，我们可以认为 Key 与 Query 相关性越高，则其所应该赋予的注意力权重就越大。

通过合理的训练拟合，词向量能够表征语义信息，从而让语义相近的词在向量空间中距离更近，语义较远的词在向量空间中距离更远。

我们往往用欧式距离来衡量词向量的相似性，但我们同样也可以用点积来进行度量：

v⋅w=∑i​vi​wi​​

根据词向量的定义，语义相似的两个词对应的词向量的点积应该大于0，而语义不相似的词向量点积应该小于0。

<br />

假设我们查询 Query 对应词向量为 q，key 对应的所有词向量为一个矩阵 k

使用矩阵乘法来计算相似度：x=qKT

再进行 softmax 转化为和为 1 的权重，再乘以对应的值（Value），得到的向量就是注意力分数

attention(Q,K,V)=softmax(qKT)v

Q 去查询 K，得到注意力权重，再对 V 加权

#

# 理解：

Transformer 的 Attention 里面，会把输入 X 变成三个东西：

Q=XWQ​

K=XWK​

V=XWV​

同一个输入 X，经过三个不同的线性变换得到的。

Q：我现在想找什么 →查询条件

K：这里有什么信息可以和需求匹配 →匹配依据

V：如果匹配上了可以拿走什么内容 →实际内容

<br />

eg.

```
Q = “Apple”

K1 = 水果
V1 = 水果是一类植物性食品...

K2 = 苹果公司
V2 = 苹果公司是一家数码产品厂商...

K3 = 汽车
V3 = 汽车是一种交通工具...

K4 = 电池
V4 = 电池是一种可以存储电能的...

```

很明显，K1 和 K2 跟 Q 的相关性较高

所以比较之后会给出一个相关程度\[0.3, 0.6, 0.05, 0.05] 这便是Attention权重

最终输出并不是 K，而是 K 代表的 V

```
Q
 ↓
和 K 比较
 ↓
得到权重
 ↓
按照权重组合 V
 ↓
得到最终结果

```

<br />

## 但实际上：

Q 是带有查询倾向的向量，可通过训练得到

K 和 Q 也是高维向量

输入的句子经过 NLP 切分成token 后，每一个 token 都有自己的 KQV

Q 负责找，K 负责匹配，V 负责提供内容

<br />

# 如何计算确定相关 token

计算要查询的 Q 与现有的 K 之间的相似程度（点积）

QKT

<br />

如果两个向量比较接近，得到的值比较大，反之比较小

<br />

## 为什么要再除以一个dK​1/2

防止点积的结果过大，softmax后太过极端，导致训练不稳定

```
[0.00001, 0.99998, 0.00001]

```

<br />

然后进行softmax转化为注意力权重百分比

softmax(QKT/dK1/2​)

再乘以 V 加权：

softmax(QKT/dK1/2​)V

<br />

<br />

# 注意

## KQV是矩阵

K 是由所有 token 的 Key 向量组成的矩阵，每个 Key 向量与同一个 token 的 Value 向量一一对应；并不是每个 V 对应一个 K 矩阵。

也就是说，所有 token 的 Key成为 K 矩阵的行向量，所有token 的 Value 成为 V 矩阵的行向量

<br />

Q:\[Nq​,dk​​]

K:\[Nk​​,dk​​]

V:\[Nv​​,dv​​]

<br />

## 注意力分数矩阵

softmax前的注意力分数矩阵，每一个行向量是一个 Q与每个 K 的相关程度，每一个列向量是一个 K与每个 Q 的相关程度

```
        K1    K2    K3    K4
Q1     1.0   2.0   3.0   1.0
Q2     2.0   1.0   4.0   2.0
Q3     1.0   3.0   2.0   1.0
Q4     4.0   1.0   2.0   3.0

```

<br />

<br />

## 为什么不直接选最大的 V？

因为 Attention 的目的不是：

> “找出一个最相关的 token。”

而是：

> **“按照相关程度，从多个 token 中融合信息。”**
>
> 这和“加权平均”很像

你可以把整个 Attention 想成：

Q → QKT判断应该关注谁 → Softmax确定关注比例 → ×V按比例融合信息

## 对于维度的理解

dK​是 K 矩阵的最后一维：每一个行向量都表示一个 k向量，那么每一个向量的列数就是向量的维数

\[batchsize,seqlen,dk​]

batch size：表示有一个 K 矩阵

seqlen：表示一个 K 矩阵的序列长度，也就是有多少个k行向量

dk：表示k向量的维度

<br />

# 自述

为了让token 带上上下文语义信息，attention 机制将输入的句子通过Tokenizer转化为 token，再通过Embedding转化为向量，用线性方式表示出每个 token 的 QKV，这三个都是包含了所有 token 的qkv 的矩阵，再让 Q 与 K 的转置矩阵相乘（因为 QK 都是从 X 得来，在自注意力机制中两个矩阵的列数相等，因此转置后满足矩阵乘法）。接着再除以dk 开方防止softmax 后过于极端干扰训练，dk 是 K 矩阵的最后一维的维度数，其表示 K 矩阵中一个k 向量的维度数，接着通过softmax 转化为注意力分数矩阵，其中有一个dim 参数，表示 softmax 沿哪一维进行运算,这里dim 一般等于-1，也就是最后一维（列），表示沿着列变化的方向进行计算，也就是一行一行计算，因为 QK^T得到的矩阵中，行向量表示一个 Q 与多个 K 之间的关系远近，列向量表示一个 K 对于多个 Q 之间的关系远近，所以要按行进行计算才能得到一个 Q 关于多个 K 的关系权重。然后再与 V 矩阵相乘，得到每个 V 的加权融合，其中既包含了关系最近的语义信息，也包含了那些关系远，但也可能有信息的 token。通过以上方式，可以让一个词包含其上下文的语义信息，比如：“小明爱吃苹果，它很好吃”中，“它”不仅有原意，还包含了“苹果”的上下文信息

<br />

```

      tokenizer      Embedding
input--------->token--------->X(矩阵向量)---> Q, K, V---> QK^T---> QK^T/√dk---> softmax---> A---> AV--->Output

```
